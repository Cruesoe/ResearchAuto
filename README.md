# Research: Auto

Research: Auto keeps your researchers working by automatically choosing the next available project whenever a research queue is empty.

Your choices always take priority. If you manually select a project, Research: Auto leaves it active and only fills research slots that are genuinely empty.

## Features

- Selects an available project when research becomes idle.
- Prefers projects that already have progress.
- Prioritizes the lowest available tech level, then the cheapest project by default.
- Can prioritize expensive projects instead.
- Can restrict choices to your faction's current tech level or ignore tech levels entirely.
- Supports separate Anomaly, gravship, and Monolyn divinitech research queues.
- Can show a notification whenever a new project is selected.

## Settings

Open **Options → Mod settings → Research: Auto** to:

- Enable or disable automatic research.
- Toggle selection notifications.
- Restrict projects to the current era.
- Ignore tech level when sorting projects.
- Prefer expensive projects.
- Include or exclude Anomaly, gravship, and Monolyn research.
